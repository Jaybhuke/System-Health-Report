#  System Health Monitoring


## Overview

This project generates system health report including CPU, memory, Disk and top processes status.


## features

- CPU usage monitoring
- Memory usage tracking
- Disk space analysis
- Top resource-consuming proecesses
- Clean formatted output

----

## Technologies used

- Linux
- Bash Scripting
- top, free , df, ps commands

---

## Usage

```bash
chmod +x system_report.sh
```
